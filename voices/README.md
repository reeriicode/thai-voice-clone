# voices/

หนึ่งโฟลเดอร์ = หนึ่งเสียง

```
voices/<id>/
├─ ref.wav      คลิปเสียง 5-8 วินาที เสียงสะอาด ไม่มีเพลง
└─ voice.json   { "name": "ชื่อที่แสดง", "ref_text": "คำที่พูดในคลิป", "gender": "male",
                  "order": 1, "edge_voice": "th-TH-NiwatNeural" }
```

- `ref_text` ต้องตรงกับที่พูดในคลิป (คำอังกฤษเขียนเป็นคำอ่านไทย) เว้นว่างได้ จะถอดเสียงให้อัตโนมัติ
- `gender` ใช้กับ `ผช:` / `ผญ:` ในบทสนทนา และเลือกเสียง Edge TTS
- `edge_voice` ไม่ใส่ก็ได้ (ผู้ชาย = th-TH-NiwatNeural, ผู้หญิง = th-TH-PremwadeeNeural)
- เพิ่มง่ายสุดผ่านแท็บ **เพิ่มเสียง** ในแอป

เสียงที่มากับ repo: `female` และ `example_male` (คลิปตัวอย่างจาก F5-TTS-THAI)
เสียงที่คุณเพิ่มเองจะไม่ถูกอัปขึ้น git (ดู `.gitignore`)
