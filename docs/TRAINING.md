# เทรนโมเดลเสียงของคุณเอง (Fine-tune)

การโคลนจากคลิป 5-8 วินาทีได้เสียง "คล้าย" แต่ถ้าอยากได้เสียงที่เหมือนและชัดกว่า ต้อง fine-tune
โมเดลไทย v1 ต่อด้วยเสียงของคุณ ผลลัพธ์คือไฟล์โมเดล `.pt` ที่เอามาวางใน `models/custom/` แล้วเลือกใช้ในแอปได้เลย

```
อัดเสียง 30-60 นาที → ตัดเป็นคลิป + ถอดข้อความ → เทรนต่อจากไทย v1 → ลดขนาดโมเดล → วางใน models/custom/
```

## 0. ต้องใช้อะไร

| | |
|---|---|
| การ์ดจอ | **12 GB ขึ้นไป** (การ์ด 4 GB เทรนไม่ไหว ใช้ **Google Colab** ฟรีได้ การ์ด T4 16 GB) |
| เสียง | อย่างน้อย 20-30 นาที แนะนำ 1 ชั่วโมงขึ้นไป |
| เวลา | ราว 2-5 ชั่วโมงบน T4 (ขึ้นกับจำนวนข้อมูล) |

## 1. อัดเสียง (สำคัญที่สุด)

- ห้องเงียบ ไม่มีเพลง ไม่มีเสียงคีย์บอร์ด/พัดลม ใช้ไมค์ตัวเดิม ระยะเดิมตลอด
- พูดหลายอารมณ์และหลายจังหวะ (ปกติ ตื่นเต้น ถาม หัวเราะ) แบบที่จะใช้จริงตอนสตรีม
- ถ้าเอาจากวิดีโอเก่า: แยกเพลงพื้นหลังออกก่อน (เช่น [UVR](https://github.com/Anjok07/ultimatevocalremovergui))
- เก็บไฟล์ไว้ใน `data/` ของโปรเจกต์นี้ (ไม่ขึ้น git) เช่น `data/my_voice_raw/*.wav`

ทั้งสองแบบจะได้หน้าเว็บเครื่องมือเทรนที่มี 5 แท็บ ทำตามลำดับ:

## 3. แท็บ "1.ถอดข้อความเสียง"

1. ตั้ง **ชื่อโปรเจกต์** (เช่น `my_voice`) กด **สร้างโปรเจกต์ใหม่**
2. เอาไฟล์เสียงยาว ๆ ไปใส่ใน `data/my_voice/dataset/` ของเครื่องมือเทรน (หรืออัปโหลดในหน้าเว็บ)
3. ภาษา `th` แล้วกด **ถอดข้อความ** เครื่องมือจะตัดเป็นคลิปสั้นและถอดข้อความให้เอง
4. **ตรวจแก้ข้อความ** ให้ตรงกับที่พูดจริง (ข้อความผิด = โมเดลออกเสียงผิด) คำอังกฤษเขียนเป็นคำอ่านไทย

ถ้าตัดคลิปเอง รูปแบบที่ใช้คือ:

```
data/my_voice/
├─ wavs/0001.wav, 0002.wav, ...     คลิปละ 3-15 วินาที
└─ metadata.csv                     wavs/0001.wav|สวัสดีครับทุกคน
```

## 4. แท็บ "2.เตรียมชุดข้อมูล"

- **ไม่ต้องติ๊ก "สร้างคำศัพท์"** ให้ใช้ vocab เดิมของโมเดลไทย (เทรนต่อแล้วคำศัพท์ต้องตรงกัน)
- กด **เตรียมข้อมูล**

## 5. แท็บ "3.ฝึกอบรม"

| ช่อง | ใส่อะไร |
|---|---|
| Tokenizer | `custom` |
| ตำแหน่ง Vocab ไฟล์ | `assets/vocab/vocab.txt` ของ repo นี้ (หรือ `vocab/vocab.txt` ใน F5-TTS-THAI) |
| ตำแหน่ง Pretrained โมเดล | ไฟล์ไทย v1: `models/downloaded/th_v1/model_1000000.pt` หรือ `hf://VIZINTZOR/F5-TTS-THAI/model_1000000.pt` |
| Finetune | ✅ ติ๊ก |
| Learning Rate | `1e-5` (ต่ำไว้ก่อน กันเสียงพัง) |
| Batch Size per GPU | กด **ตั้งค่าอัตโนมัติ** ก่อน (บน T4 ราว 3000-6000) |
| Epochs | เริ่ม 50-100 แล้วค่อยดูผล |
| Mixed Precision | `fp16` |

กด **เริ่มฝึกอบรม** แล้วรอ จะได้ checkpoint เป็นระยะใน `ckpts/my_voice/model_XXXX.pt`

## 6. แท็บ "4.ทดสอบโมเดล"

ลองสร้างเสียงจากแต่ละ checkpoint เลือกอันที่ฟังดีที่สุด (อันล่าสุดไม่จำเป็นต้องดีที่สุด
ถ้าเทรนนานเกินไปเสียงอาจแข็งหรือเพี้ยน)

## 7. แท็บ "5.ลดขนาดโมเดล"

checkpoint ตอนเทรนใหญ่ ~5.4 GB (มีข้อมูลสำหรับเทรนต่อ) ให้ลดขนาดก่อนเอาไปใช้:

- **ตำแหน่ง Checkpoint**: ไฟล์ที่เลือกจากข้อ 6
- ✅ **บันทึกจุดตรวจ EMA**
- กด **ลดขนาดโมเดล** ได้ไฟล์ ~1.3 GB

## 8. เอามาใช้ในแอปนี้

1. คัดลอกไฟล์ไปไว้ที่ `models/custom/my_voice.pt`
2. (ไม่บังคับ) สร้าง `models/custom/my_voice.json` เพื่อตั้งชื่อ:
   ```json
   { "name": "เสียงผม (เทรนเอง)", "arch": "v1", "vocab": "thai", "ipa": false, "thai": true }
   ```
3. เปิดแอปใหม่ (`start.bat`) เลือกโมเดล **เสียงผม (เทรนเอง)** และเลือกเสียง (คลิปของคุณ) ใน voices/
4. แบบคำสั่ง: `.venv\Scripts\python speak.py --model custom_my_voice --text "สวัสดีครับ"`

## ปัญหาที่พบบ่อย

| อาการ | แก้ |
|---|---|
| Out of memory ตอนเทรน | ลด Batch Size per GPU ลงครึ่งหนึ่ง |
| เสียงที่ได้แตก/เพี้ยน | Learning rate สูงไป หรือเทรนนานไป ลองใช้ checkpoint ก่อนหน้า |
| อ่านคำผิดเป็นประจำ | ข้อความใน metadata ไม่ตรงกับเสียง กลับไปแก้ข้อ 3 |
| เสียงไม่ค่อยเปลี่ยนจากเดิม | ข้อมูลน้อยไป หรือเทรนน้อยไป เพิ่มเสียง/เพิ่ม epochs |
| โหลดโมเดลในแอปไม่ได้ (size mismatch) | ตั้ง `arch`/`vocab` ใน .json ให้ตรงกับที่เทรน (เทรนจากไทย v2 ใช้ `"arch": "v2", "vocab": "thai_ipa", "ipa": true`) |
