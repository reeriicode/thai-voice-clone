วางไฟล์โมเดล F5 ที่ train เอง (.pt หรือ .safetensors) ไว้ในโฟลเดอร์นี้ แล้วเปิดแอปใหม่
จะขึ้นในช่อง "โมเดล" ให้เลือกอัตโนมัติ

ถ้าโมเดลเป็นแบบ v2 (IPA) หรืออยากตั้งชื่อเอง ให้สร้างไฟล์ .json ชื่อเดียวกัน เช่น my_voice.pt -> my_voice.json
{ "name": "เสียงผม (train เอง)", "arch": "v1", "vocab": "thai", "ipa": false, "thai": true }

ไม่มี .json = ใช้ค่าแบบ ไทย v1 ซึ่งตรงกับการ fine-tune ต่อจากโมเดลไทย v1

ไฟล์ในโฟลเดอร์นี้ไม่ถูกอัปขึ้น git (ไฟล์ใหญ่)
